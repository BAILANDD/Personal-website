Project Introduction

《童年的消逝》是一件围绕儿童认知、媒介环境与数字图像关系展开的互动装置作品。项目关注当儿童持续接触屏幕、网络图像与数字媒介后，现实经验与虚拟信息之间的边界如何逐渐发生变化。作品通过 TouchDesigner 构建实时视觉系统，将观众的操作转化为图像状态、运动、失真与模糊等视觉变化，使观看者直接参与作品的生成过程。

Background

项目的前期研究围绕儿童成长环境、媒介使用方式与视觉认知展开，并尝试梳理数字媒介进入儿童日常生活之后，对认知方式、信息接收和成长经验所产生的变化。

Media Impact

数字媒介已经深度进入儿童的日常生活。屏幕、短视频、游戏与网络信息不断改变儿童获取信息和理解世界的方式，同时也让现实经验与虚拟内容之间的边界变得更加模糊。项目通过前期研究梳理这些变化，并将其转化为后续作品中的视觉与交互线索。

Design Development

设计阶段主要围绕视觉元素、交互方式与空间呈现之间的关系展开。通过草图与系统结构梳理，将儿童、媒介信息、图像干扰与实时生成逐步整合为统一的交互体验。

Interaction Principle

作品通过实体控制与 TouchDesigner 实时视觉系统建立互动关系。观众的操作可以改变图像状态、运动速度、失真程度、模糊与视觉效果，使原本固定的影像不断发生变化。最终画面并不是预先播放的单一结果，而是在观众参与过程中持续生成。

Final Installation

最终装置将实时生成的视觉内容、交互设备与空间环境结合，使观众的操作直接成为作品视觉变化的一部分。

Virtual Exhibition

虚拟展览部分进一步模拟作品在展示空间中的观看关系，用于呈现影像尺度、装置位置与观众观看距离之间的空间效果。

Project Introduction

《珊瑚泣韵》以珊瑚的自然形态与生态意象为视觉出发点，通过 3D 建模、数字绘制与图像合成等方式，将珊瑚的结构、纹理与色彩转化为具有空间感与叙事性的视觉场景。项目尝试在自然形态与数字媒介之间建立新的视觉关系，使珊瑚从现实中的生态对象转化为一种可被重新观看和感知的数字景观。

Background Research

前期研究从珊瑚的生长结构、形态特征、色彩层次与生态环境展开，通过图像资料与视觉归纳提取可用于后续创作的形态语言，为场景构图、色彩系统与细节设计建立基础。

Research / Context

珊瑚既具有高度复杂的自然结构，也承载着脆弱的生态关系。项目希望通过视觉设计重新组织这些信息，使环境议题不只停留在知识层面，而能够转化为更加直观的视觉体验。

Sketch Development

草图阶段主要探索珊瑚主体、环境元素与画面空间之间的关系，通过不同构图与形态组合确定最终场景的视觉重心与层次结构。

Final Details

最终画面通过局部纹理、颜色叠加与空间层次进一步强化珊瑚的有机感。细节既保留自然形态的复杂性，也通过数字处理形成更具幻想感的视觉语言。

LIL.LIT

二手母婴产品 APP

Project Background

LIL.LIT 是一款面向年轻父母的二手母婴用品交易与育儿信息平台。项目关注母婴用品使用周期短、闲置率高以及二手交易过程中信任与信息筛选成本较高等问题，希望通过更加清晰的交易流程、商品信息结构与社区内容，为用户建立更安全、便捷的使用体验。

Task

基于前期研究，项目进一步明确核心设计任务，并将用户在商品交易、信息获取与育儿交流过程中的主要问题转化为具体的产品设计目标。

Persona

通过目标用户画像进一步梳理年轻父母在时间、预算、商品安全与育儿信息获取方面的需求，为后续功能与流程设计提供用户依据。

Storyboard

故事版将用户需求放入实际生活场景中，用于观察用户从产生需求、寻找商品到完成交易与获取相关信息的完整使用过程。

User Flow

用户流程进一步整理了商品浏览、筛选、交易、发布以及社区内容等主要功能之间的关系，并用于确认核心任务的操作路径。

System Map

在用户流程基础上，将产品功能进一步整理为系统结构，明确不同功能模块与信息层级之间的关系。

Design System / Visual Spec

视觉系统围绕柔和、友好与可信赖的产品气质建立统一的色彩、字体与界面组件规范，为后续页面设计保持一致性。

Low-Fidelity Prototype

低保真阶段主要验证页面信息结构、核心功能位置与主要任务路径，在进入视觉设计前确认产品结构是否清晰可用。

User Testing

通过原型测试观察用户完成核心任务时的操作路径与理解成本，并记录流程、信息层级与界面反馈中仍需要调整的问题。

Iteration / Optimization

根据测试结果对页面结构、操作路径与信息展示方式进一步调整，在保持核心功能完整的同时降低操作复杂度，并强化主要信息的视觉层级。

PROJECT INTRODUCTION

《SUICIDIO》是一件围绕病毒传播、社会恐惧与个体心理焦虑展开的生成影像作品。作品将病毒视为一种关于恐惧扩散的视觉隐喻，通过高饱和色彩、流体结构与不断生长、扭曲的有机形态，构建介于微观生物与抽象数字景观之间的视觉状态。项目主要在 TouchDesigner 中完成，通过编写 Shader 控制核心动态视觉，使图像产生类似病毒扩散、聚合与形态变化的生成效果，并结合音频分析让视觉随声音实时响应；后期使用 After Effects 对影像与音乐节奏进行进一步整理和剪辑，最终形成一套关于未知威胁、传播与心理压迫的动态视觉表达。

TECHNICAL PROCESS

作品的核心动态视觉在 TouchDesigner 中通过 Shader 构建。通过编辑 Shader 参数与图像处理逻辑，使基础视觉不断发生扩散、扭曲、聚合与形态变化，形成类似病毒生长和传播的动态效果。在此基础上进一步结合音频分析，将声音中的节奏与强度映射到视觉参数，使图像能够随声音实时产生变化，从而建立声音与生成视觉之间的动态关系。

FINAL VISUALS

最终视觉通过不同的粒子、流体与有机形态变化呈现病毒扩散的不同状态，使同一套生成系统在时间过程中持续产生新的视觉结果。
